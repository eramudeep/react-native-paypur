# react-native-paypur

No paperwork, just sign up. Add your UPI ID, get your gateway keys, and start accepting payments from 100+ UPI apps worldwide.

## Installation


```sh
npm install react-native-paypur
```


## Usage


```js
import { multiply } from 'react-native-paypur';

// ...

const result = multiply(3, 7);
```
